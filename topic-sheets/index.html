How to use the sheets
  1. Pick a skill and start with Sheet 1. Every sheet in a skill has the same Easy, Medium and Hard mix, running easy to hard like a real module.
  2. Sign in, then work through the 22 questions against the 35-minute clock. The Desmos calculator, reference sheet and scratchpad are built in.
  3. Read the Score Gap Report and College Board’s explanation for each question you missed. Aim for 80% before moving to the next sheet.
  4. Where a skill’s questions don’t divide evenly by 22, its sheets reuse a few questions from its other sheets. These are labelled in the review. The Inference sheet adds 9 One-variable data questions, because the bank has only 13 on inference and statistical claims.
